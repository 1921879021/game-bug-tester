# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Technical disagreement is welcome; personal attacks, harassment, discrimination, and deliberate disruption are not.

## Scope

This applies to issues, pull requests, discussions, examples, documentation, and other project spaces maintained for Game Bug Tester.

## Reporting

If a conduct issue cannot be handled in public, contact the repository maintainer through the private contact method configured on the GitHub repository. Do not post private personal information in a public issue.
