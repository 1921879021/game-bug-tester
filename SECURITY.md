# Security and safety

Game Bug Tester is intended for software and environments you are authorized to test.

Do not use the skill to automate destructive actions against production services, real-money economies, third-party accounts, or systems you do not own or have explicit permission to test.

High-risk operations such as real purchases, production currency mutation, deliberate save corruption, network fault injection, account deletion/ban flows, credential testing, and migration/destructive-state tests require an isolated local/test environment.

## Reporting a security issue in this repository

Before public release, configure a private maintainer contact or GitHub private vulnerability reporting. Once configured, use that channel for security issues in Game Bug Tester itself.

Do not include credentials, private production data, proprietary game source, access tokens, or personally identifying information in public issues.
