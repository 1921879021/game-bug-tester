# UI 功能测试

## UI 模式

- UI-001 按钮无响应：可见、可用状态下点击无反馈且目标动作未发生。
- UI-002 重复提交：单击/连点触发多次交易、领奖、页面叠加。
- UI-003 遮挡/不可点击：弹窗、刘海/安全区、不同分辨率导致关键控件不可达。
- UI-004 状态不同步：金币/HP/装备/任务 UI 与真实状态不一致。
- UI-005 弹窗栈错误：A→B→返回时层级/遮罩/焦点错误。
- UI-006 错误返回：Back/Esc 关闭错误层级或退出游戏。
- UI-007 滚动/列表边界：0 项、1 项、大量项、最后一项、动态刷新。
- UI-008 分辨率/缩放：16:9、16:10、21:9、竖屏/横屏、系统缩放导致截断。
- UI-009 Loading 输入穿透：加载遮罩期间点击影响后层。
- UI-010 禁用态仍执行：灰色按钮仍能触发逻辑。

## Oracle

UI 测试既检查“能否操作”，也检查“操作结果是否与状态一致”。像素差异只作为视觉异常证据，不能替代功能 oracle。
