# Navigation / Collision / Physics 测试

## NAV

- NAV-001 卡死点：输入持续存在但角色位置长期不变化，且并非设计阻挡/眩晕。
- NAV-002 掉出地图：角色位置越过合法地图边界或落入无恢复区域。
- NAV-003 不可达关键点：任务/出口/必经交互点因导航或阻挡无法到达。
- NAV-004 传送位置错误：传送后进入墙体、空气、封闭区域或错误关卡。
- NAV-005 Respawn 错位：复活点与安全区/检查点设计不一致。

## PHY

- PHY-001 穿墙：高速移动、冲刺、跳跃、斜角、门关闭瞬间测试。
- PHY-002 穿地/掉图：坡面、台阶、边缘、加载边界、移动平台。
- PHY-003 碰撞抖动/弹飞：角色与动态刚体、狭窄空间、多物体堆叠。
- PHY-004 物体卡入角色/墙：拾取、推动、投掷、载具碰撞。
- PHY-005 高速 tunneling：高速投射物/载具跳过碰撞检测。
- PHY-006 移动平台脱离：跳跃、蹲伏、暂停恢复、网络延迟后位置不同步。

## 推荐边界点

墙角、门框、斜坡、楼梯、移动平台、地图接缝、传送门、出生点、薄碰撞体、可破坏物旁。

## Oracle

若可读坐标/碰撞层：使用合法区域/碰撞状态；黑盒时使用连续画面证据 + 明确不可达/越界结果。对“视觉穿模但碰撞仍正常”分类到 VIS，而不是 PHY。
