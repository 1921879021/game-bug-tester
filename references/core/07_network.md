# Network / Multiplayer 测试

## Bug patterns

- NET-001 多客户端关键状态不同步。
- NET-002 超时/重试造成重复交易或奖励。
- NET-003 临时断线后永久卡在连接状态。
- NET-004 重连后玩家状态丢失或错误。
- NET-005 房主退出导致房间卡死或错误结算。
- NET-006 匹配取消与成功并发导致异常状态。
- NET-007 结算/领奖与断线重连竞态造成奖励重复或丢失。
- NET-008 多人同时拾取/交互造成重复归属。
- NET-009 延迟/抖动/丢包后客户端长期不收敛。
- NET-010 服务端超时/错误后客户端永久卡住。
- NET-011 重连生成重复玩家实体/幽灵角色。
- NET-012 重连后重放陈旧输入/命令。
- NET-013 房主迁移后权威状态丢失或双主。
- NET-014 重复包/乱序消息导致命令重复或错序。
- NET-015 多人场景切换不同步。

## Oracle

优先服务端权威状态、账本、ownership/session telemetry；其次比较多个客户端在项目声明窗口后的最终收敛结果。短暂的客户端预测/插值差异不能直接判 Bug。

## 安全边界

断连、延迟、丢包、host leave、重复请求等故障注入仅允许隔离 QA/Test 环境。不得默认对生产账号、公共服务器或第三方服务执行主动网络干预。
