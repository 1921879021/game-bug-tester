# Gameplay / Character / Input 测试

## GAME 逻辑

- GAME-001 伤害/治疗数值异常：检查 before + delta = after，考虑护盾/减伤/暴击等设计修正。
- GAME-002 技能冷却绕过：快速连按、切武器/界面、死亡复活、切场景后检查 CD。
- GAME-003 道具重复获取/消耗：拾取、满背包、断线、切场景交叉。
- GAME-004 任务状态跳转错误：接受→完成→领奖，检查重复领奖、无法领奖、先完成后接任务。
- GAME-005 商店经济错误：0/不足/刚好/超大金额；购买失败是否扣款，成功是否只扣一次。
- GAME-006 重复触发奖励：连点领奖、网络重试、返回重进、断线重连。
- GAME-007 条件判断错误：等级/道具/前置任务边界值 N-1、N、N+1。

## CHAR 状态机

- CHAR-001 Death → Attack/Input：死亡态不应继续产生战斗行为，除非设计允许。
- CHAR-002 Stun → Dash/Skill：受控态是否可非法脱离。
- CHAR-003 Animation lock：动作结束后仍不能移动/攻击。
- CHAR-004 Respawn state leak：复活后保留不应存在的无敌、Buff、碰撞关闭、速度修改。
- CHAR-005 Equip state mismatch：模型/属性/背包装备状态不一致。

## INPUT

- INPUT-001 单次输入重复触发：一次点击导致多次购买/领奖/跳转。
- INPUT-002 快速连点越权：按钮禁用期间仍执行。
- INPUT-003 同时输入冲突：移动+攻击+菜单、跳跃+冲刺+交互。
- INPUT-004 焦点丢失：Alt-Tab/前后台后键鼠/触控不再响应或持续按下。
- INPUT-005 控制方案切换：手柄↔键鼠/触控切换后提示与实际输入不一致。

## 判定

优先使用状态变量、资源数值、角色能力、UI 状态与实际行为的一致性作为 oracle；仅凭动画“看起来奇怪”不要直接判逻辑 Bug。
