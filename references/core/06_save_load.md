# Save / Load 测试

存档问题默认高风险，因为可能造成玩家进度损失。

## 核心模式

- SAVE-001 保存后字段丢失：等级、货币、装备、任务、位置、设置等关键字段前后不一致。
- SAVE-002 回档：保存成功提示后重启仍恢复旧状态。
- SAVE-003 坏档/无法加载：合法操作序列产生无法读取存档。
- SAVE-004 场景切换竞态：保存与传送/死亡/退出同时发生造成部分字段新、部分字段旧。
- SAVE-005 多槽覆盖错误：保存槽 A 覆盖 B。
- SAVE-006 云/本地冲突：选择策略与实际结果不一致（仅在有该功能时）。
- SAVE-007 版本升级迁移：旧版本存档在新版本读取失败或关键字段错误。
- SAVE-008 设置持久化错误：音量、键位、画质、语言重启后异常。

## 快照 Oracle

保存前生成关键状态快照：

`{progress, inventory, currency, equipment, quest, position/checkpoint, settings}`

重新加载后按设计允许的字段逐项比较。必须排除设计上不会持久化的临时状态。

## 破坏性保护

优先测试账号/复制存档；若无法备份，不进行可能损坏唯一真实存档的 Chaos 测试。
