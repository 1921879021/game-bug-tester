# Graphics / Animation / Audio 测试

## VIS

- VIS-001 模型/纹理缺失、粉色/错误材质
- VIS-002 角色/装备视觉穿模（功能碰撞正常）
- VIS-003 LOD 跳变、消失、距离阈值异常
- VIS-004 摄像机穿墙/裁剪错误
- VIS-005 动画 T-pose、冻结、错误混合
- VIS-006 动画与逻辑不同步：已攻击但动画未播/反之
- VIS-007 特效残留或不消失
- VIS-008 分辨率/HDR/窗口模式渲染错误

## AUDIO

- AUDIO-001 应播放但无音效
- AUDIO-002 单次事件重复叠加播放
- AUDIO-003 场景切换后音乐叠加/不停止
- AUDIO-004 暂停/切后台后音频状态错误
- AUDIO-005 音量设置未生效或重启丢失
- AUDIO-006 3D 空间音源方向/距离明显错误
- AUDIO-007 语音/字幕时序错位（若有明确基线）

## Oracle

视觉优先与基准截图/设计稿/同版本参考状态比较；音频优先以事件触发规则、音轨状态和设置值为依据。纯审美差异不作为功能 Bug。
