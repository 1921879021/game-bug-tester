# Severity / Priority 规则

Severity 描述影响，Priority 描述修复紧急度。二者不要混用。

## Severity

### S0 / Blocker

- 无法启动/无法进入核心游戏
- 稳定复现的关键流程崩溃或永久卡死
- 存档损坏/大面积不可恢复进度丢失
- 核心联网模式无法进行

### S1 / Critical

- 能继续但核心玩法严重失效
- 稳定穿墙/掉出地图导致关卡无法继续或重大作弊结果
- 重复购买/领奖/货币错误造成重大经济影响
- 多人关键状态严重不同步
- 高频崩溃但存在规避路径

### S2 / Major

- 重要功能失败，有可接受绕行
- UI 关键按钮特定条件失效
- 明显性能回归影响游玩
- 任务/技能/装备逻辑在部分场景错误

### S3 / Minor

- 非关键视觉/动画/音频异常
- 低频、影响有限、容易恢复的问题

### S4 / Cosmetic

- 纯表现瑕疵，不影响功能和理解

## Priority 建议

- P0：阻塞发布/线上紧急
- P1：当前版本必须修
- P2：计划内尽快修
- P3：可排期

## 升级因素

同一 Severity 可因以下因素提高 Priority：

- 复现率高
- 影响新手/主线/付费/登录
- 无 workaround
- 影响大量设备/平台
- 已在线上广泛发生
- 存在数据污染/经济扩散风险
