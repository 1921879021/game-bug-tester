# Performance 测试

## 先有基线再判定

性能高度依赖设备、场景、画质和目标帧率。优先使用项目基线/性能预算；没有基线时只报告“观测异常/疑似回归”，不要凭固定通用数字武断判 Bug。

## 模式

- PERF-001 特定场景 FPS 持续下降
- PERF-002 明显 frame-time spike / 卡顿
- PERF-003 内存随重复操作持续单向增长且不回收
- PERF-004 场景/资源加载时间异常增长
- PERF-005 大量 NPC/粒子/掉落导致不可玩
- PERF-006 长时间运行性能逐步恶化
- PERF-007 UI 列表/背包大量对象导致卡顿
- PERF-008 切前后台/分辨率后 GPU/CPU 异常占用

## 推荐采样

设备、分辨率、画质、场景、测试时长、平均/1% low 或 frame time、峰值内存、加载耗时。若只能黑盒观察，保留录像与明确的输入-反馈延迟描述。
