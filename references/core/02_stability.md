# Stability 测试

## 高价值模式

### STAB-001 启动崩溃/无法启动
触发：首次启动、升级后启动、无网络启动、低磁盘/权限异常（安全范围内）。
Oracle：进程应稳定进入首个可交互状态；不得出现 fatal/未处理异常导致进程退出。
证据：启动日志、崩溃栈、录像、系统事件。

### STAB-002 场景切换崩溃
触发：连续进入/退出关卡、传送、主菜单↔游戏、死亡重载。
Oracle：每次切换完成且新场景可交互；无 crash/hang。

### STAB-003 长时间运行卡死
触发：长时间挂机、长战斗、连续 UI 操作。
Oracle：主线程/画面/输入仍有响应；进程未进入系统“未响应”。

### STAB-004 反复操作后黑屏
触发：暂停、切前后台、切分辨率、加载/取消加载、退出再进入。
Oracle：存在明确可恢复画面；若黑屏是加载设计，必须在合理时间内结束。

### STAB-005 异常资源状态崩溃
触发：背包满、0 血、0 金币、最大等级、空列表、无可选目标。
Oracle：边界状态应被逻辑处理，不因 null/empty/index/overflow 导致崩溃。

## 测试建议

先运行 Smoke，再进行 20–100 次关键循环：进入关卡→操作→退出/重载。若存在日志接口，优先捕获 fatal、exception、assert、out-of-memory、device lost 等关键词，但日志关键字本身不等于最终 Bug，仍需结合实际影响。
